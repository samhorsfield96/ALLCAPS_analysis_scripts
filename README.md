# ALLCAPS analysis scripts

This repository contains the R and Python scripts used to benchmark serotype prediction, assess novelty detection, merge benchmark outputs, and generate the paper figures for the ALLCAPS pipeline.

The analysis is organized around benchmark datasets stored under the `data/` directory.

## Main analysis scripts

### [ATB_knn_analysis.R](ATB_knn_analysis.R)
Combines ALLCAPS predictions for the ATB dataset with nearest-neighbour distance outputs. It joins sample-level predictions to KNN labels, evaluates each candidate against the per-serotype novelty threshold, and writes a merged table to `data/ATB_query_results_knn.csv`. Use after [calculate_novel_knn.R](calculate_novel_knn.R) and before [analyse_ATB_data.R](analyse_ATB_data.R) to generate Figure 5.

### [analyse_ATB_data.R](analyse_ATB_data.R)
Builds the ATB-specific analysis pipeline. It reads the tree and prediction tables, filters to the best sample call per isolate, assigns novelty/non-CPS labels, merges metadata from PopPUNK, and prepares the parsed ATB result tables used for downstream plotting and phylogenetic summaries. Use after [ATB_knn_analysis.R](ATB_knn_analysis.R) to generate Figure 5. 

### [calculate_metrics.R](calculate_metrics.R)
Computes classification metrics for each tool and benchmark. It evaluates exact serotype matches, within-serotype matches, and serogroup matches, then writes confusion matrices and a combined metrics table to `data/metrics_all.csv`. Use after [merge_benchmark_data.R](merge_benchmark_data.R) and before [plot_metrics.R](plot_metrics.R) to generated Figure 2.

### [calculate_novel_knn.R](calculate_novel_knn.R)
Performs the novelty detection analysis for the kNN pipeline. It reads the per-k KNN datasets, fits ROC-based thresholds for each serotype and overall, classifies training/testing genomes as novel or known, and saves the resulting metrics and distance summaries for later plotting.

### [count_training_allcaps.R](count_training_allcaps.R)
Checks which ground-truth serotypes are missing from the ALLCAPS predictions in the GPS benchmark training data. It reports missing serotypes by count and writes a summary CSV into `data/`.

### [create_knn_dataset.R](create_knn_dataset.R)
Builds merged KNN distance datasets for the workflow. It transforms the raw nearest-neighbour output files into per-k training and held-out data frames and writes `k*_knn_data.csv` files for downstream novelty analysis. Use before [plot_novel_knn.R](plot_novel_knn.R) to generate Figure 4.

### [cps_accuracy_ALLCAPS.R](cps_accuracy_ALLCAPS.R)
Evaluates ALLCAPS accuracy with respect to CPS/non-CPS classification. It reads each benchmark’s ground truth and prediction files, merges them, computes performance metrics, and writes a summary table to `data/cps_accuracy_ALLCAPS.csv`.

### [merge_benchmark_data.R](merge_benchmark_data.R)
Creates the shared benchmark datasets used by the main comparison workflow. It merges output files across benchmark directories into long and wide tabular formats, keeping only samples available across tools, and saves the resulting wide/long benchmark tables in `data/`. Use before [calculate_metrics.R](calculate_metrics.R) to generated Figure 2.

### [plot_ablation.R](plot_ablation.R)
Generates ablation plots comparing ALLCAPS and ProkBERT performance under the same benchmark data. It writes boxplot summaries for serotype and serogroup performance, and is focused on the ablation analysis rather than the main benchmarking suite.

### [plot_metrics.R](plot_metrics.R)
Produces the main benchmark summary figures. It reads `data/metrics_all.csv`, builds boxplots of sensitivity/specificity/precision/F1 for each benchmark and analysis type, and also compares ALLCAPS performance against SeroBA and Pneumo-Typer.

### [plot_novel_knn.R](plot_novel_knn.R)
Visualises the kNN novelty detection sweep. It aggregates AUROC and classification metrics across k values, plots sensitivity/specificity across thresholds, and creates the distance-based novelty plots used in the kNN analysis. Use after [create_knn_dataset.R](create_knn_dataset.R) to generate Figure 4.

### [plot_serotype_distribution.R](plot_serotype_distribution.R)
Summarises serotype counts across benchmark datasets and produces the distribution plots used to inspect dataset composition. It also creates a contig-level merged truth table for additional analysis.

## Expected inputs

Most scripts expect files within the `data/` directory, including benchmark subfolders, ground-truth CSVs, predicted serotype CSVs, nearest-neighbour distance files, and summary tables generated by earlier steps in the pipeline.
